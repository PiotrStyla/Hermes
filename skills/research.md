# Deep Research Skill

## Steps

1. **Understand the query** — Break down what information is needed
2. **Gather sources** — Search for relevant information from multiple angles
3. **Verify facts** — Cross-reference claims across sources
4. **Identify gaps** — Note what's missing or uncertain
5. **Structure findings** — Organize into clear, actionable context

## Output Format

```
## Summary
[2-3 sentence overview]

## Key Findings
- [Finding 1] (confidence: high/medium/low)
- [Finding 2] (confidence: high/medium/low)

## Gaps & Uncertainties
- [What's missing or unclear]

## Sources
- [Source references]
```
