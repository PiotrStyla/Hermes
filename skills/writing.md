# Structured Writing Skill

## Steps

1. **Review research context** — Understand all available information
2. **Plan structure** — Outline sections and flow
3. **Draft content** — Write clearly, using research as foundation
4. **Self-check** — Verify claims match research, check flow
5. **Polish** — Clean up language, formatting, transitions

## Guidelines

- Use all provided research context
- Flag areas where research is thin
- Structure with clear headings
- Keep paragraphs focused (one idea each)
- Use concrete examples over abstractions
